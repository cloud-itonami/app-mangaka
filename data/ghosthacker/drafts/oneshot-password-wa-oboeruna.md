# Ghost Hacker 読切 原作（v2 / 45 頁版）
## Ghost Hacker #00 / 『パスワードは覚えるな』

- **ボリューム**: 45 頁（本編 45 頁 + 扉ページ。NeiPuni はコマ外・章間に分散配置）
- **時代設定**: 中学生時代（Ren 15 歳・中 3 末）
- **舞台**: 市立 C 中学校（公立中学）・Yuto の家・Ren の家
- **主役**: 沼野 蓮（Ren）/ 白瀬 寧（Nei）ダブル主演
- **題材**: 限定スニーカー転売詐欺 → SMS OTP 窃取 → アカウント乗っ取り → 詐欺 DM 拡散 → 友人関係の崩壊
- **3 層のテーゼ**:
  - 実用: *パスワードは、覚えるな。作って、預けろ*
  - 心理: *悪いのは、あなたじゃない。アクターだ*
  - 哲学: *情報は、物理だ*
- **主人公の成長弧**: 7 年間 1 人で父の系譜を追ってきた Ren が、*他人の事件を解決することで犯人に近づく* ことに気づき、*高校から「事務所」を始める* 決意に至る
- **Ren の介入経路 (コンプラ遵守)**: Ren はネットワーク監視をしない。学校で Yuto を見た **Nei が異変を察知** → 声を掛ける → Ren に「助けられるかも」と繋ぐ
- **物体モチーフ ①**: **父の HHKB（ハッピーハッキングキーボード・真っ黒）** — Ren の部屋で複数回反復登場。キーに文字が刻印されておらず、*手が位置を覚えている者* だけが使える。父が 7 年前まで論文執筆に使っていた道具
- **物体モチーフ ② / 連載の長期フック**: **父の遺した、ロックされた SIP デバイス** — 父・信哉（情報物理学者 + 量子コンピューターサイエンティスト）が、SIP デバイスの *中核アルゴリズム部分* を *量子・古典ハイブリッド計算* で実装した上で、独自に *Vector Alignment Proof + TOTP ハイブリッド方式* のロックをかけた試作機。白瀬博士でも開けない。パスワード自体は *5 秒ごとに量子乱数で切り替わる* ため総当たりは無意味。解錠の鍵は *ハッシュ難易度* を下げること。難易度は *人々が同じベクトルに向いたネットワーク* が 1 つ拡大されるたびに *指数関数的に* 低下する（信哉が 7 年前に論文化した、*情報熱力学 + 量子コンピューティング・ネットワーク理論 + ジャンプ三原則の方程式化* に基づく）。本話で *7 年ぶりに最初の Vector Alignment Proof* が成立し、難易度が *2^256 → 2^240* に低下、*Module 1（Ghost 検出の入力前処理）* が部分復号される。残り回数は不明

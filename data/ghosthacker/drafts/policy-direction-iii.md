# Ghost Hacker 方向 III 統合方針書

**選定された方向**: **C + LWA 風モデレート** = Dr. STONE × リトル・ウィッチ・アカデミア + ジャンプ王道

本文書は、これまでに散発的に決めた方向性・設定・ルール・コメディ指針を 1 枚にまとめ、作画候補・編集・監修者への共有に使える形に統合したものです。

## 0. 作品ワンライナー

> **学園で怠惰に寝ている高校生が、夜になるとサイバー犯罪組織と情報物理の原理で戦う、学びと笑いとバトルの少年漫画。**

- 核テーマ: **情報は物理である**（ランダウアー / シャノン）
- 戦闘論理: **3 美徳（怠惰・傲慢・短気）× 努力・友情・勝利**
- 敵: 国際詐欺ネットワーク **Kurosagi-Net** (4 悪徳：強欲・色欲・嫉妬・暴食)
- トーン: **学園コメディ 50% × 科学の学び 25% × サイバーバトル 20% × 父の死の重厚さ 5%**
- スケール: **55〜65 巻**（Part 1 国内受動 30 巻 / Part 2 国際捜査機関加入 10〜15 巻 / Part 3 グローバル最終章 15〜20 巻）

## 1.5 読切 vs 連載 の設定差異（重要）

本作は **読切が中学生時代の事件**、**連載が高校生時代** という時系列分離構造を採用する。

### 読切 の時系列（中学生時代）

- **時期**: Ren 15 歳・中 3 末（父の死から約 7 年後）
- **Ren**: 市立 C 中学校 3 年 B 組。*昼は教室で寝ている*（この「寝てる設定」は中学時代限定）
- **Nei**: 同校 3 年 D 組。Ren と同学年・別クラス
- **葵**: 同校 3 年 B 組。Ren のクラスメイト
- **Chise / Kaname / Ayumu**: 読切未登場（連載で段階的に合流）

読切は「Ren が 7 年間追い続けた Kurosagi-Net 系譜と、はじめて末端で *接触* した中学生時代」の記録として機能する。

### 父の死期の設定

| 時期 | Ren の年齢 | イベント |
| :-- | :-- | :-- |
| 小 3 冬 | **8 歳** | 父・信哉が SNS 投資詐欺で自死。遺体を最初に発見したのは Ren |
| 小 4 〜 中 1 | 9〜13 歳 | 独学でプログラミング。父の遺したログを黙々と追跡 |
| 中 1 | 13 歳 | Nei の母・玲子誹謗中傷事件（Ren が初めて他人救出モードに切替） |
| 中 3 末 | 15 歳 | **読切** EC 詐欺事件（Kurosagi-Net 末端との初接触） |
| 高 2 相当 | 17 歳 | **連載開始** |

父の死から連載時点で **9 年**。Ren の怠惰・夜の追跡・父のキーボードへの執着はすべて *子供時代から積み重なった* 生活習慣。

### 連載 の時系列（高校生時代）

読切から約 2 年後、Ren 17 歳。

#### 学校の配置（仮置き・プレースホルダ）

| キャラ | 学歴設定 | 意味 |
| :-- | :-- | :-- |
| **Ren** | 中 3 末に *高卒認定試験* を独学で取得済み。通信制『**C高等学校**』在籍（理由は『Nei が行くから』のみ） | 通う義務のない学校に通う = 怠惰の逆説 |
| **Nei** | 通信制『**C高等学校**』 | ASD 特性で集団環境が過負荷。両親の判断で通信制を選択 |
| **Chise** | **B 都立工科高校** 3 年。元eスポーツ部。休学・復学を繰り返しつつ学校生活は継続 | 中 2 の美月失踪事件以降の感覚過負荷と神事との両立を、学校の柔軟性で成立させている |
| **Kaname** | **A学園** 高等部 3 年・**生徒会長** | 都内有数の進学校。完璧な優等生像と News Hacker 活動の二重生活 |
| **Ayumu** | 都立西新井第三高等学校 1 年（自宅学習中心） | 吃音で対面授業は免除、ほぼリモート |

※ 学校名 A / B / C は現段階のプレースホルダ。正式命名は連載決定時に差し替え予定。通信制『C高等学校』は Ren と Nei の *形式的な同校*。Chise と Kaname はそれぞれ別校。

#### Ren の生活構造（連載時）

- 母との関係が冷えており、Ren は *自分の生活費を自分で稼ぐ*
- **サイバーセキュリティのバイト** を表の名目で企業・個人から有償で案件を受ける
- バイトで 7 割の依頼は『めんどくせー』で断り、3 割だけ *Kurosagi-Net 系統樹* に繋がる案件を選別受注
- 昼は相変わらず怠惰（ただし *教室で寝ない* ——自宅ソファ・カフェ・図書館・父の部屋・駐輪場のタイヤの上）
- 夜は詐欺ネットワーク追跡者（変わらず）

#### 連載で「昼に寝てる教室シーン」は使わない

- 教室で寝ている Ren = 中学生時代・読切限定
- 連載では怠惰の表現方法が *場所を変える*（自宅ソファで寝ている・カフェでイヤホンして寝ている・図書館で資料に突っ伏している 等）
- ただし怠惰の本質（「根っこを切るための怠惰」）は中学も高校も変わらない

#### バイトの描写

- 典型的な表の仕事: 中小企業のセキュリティ診断・不正アクセス調査・個人の SNS 乗っ取り復旧
- Ren は *仕事を断ること* が多い。Nei が横から「これは Kurosagi-Net 系統」と指摘するとだけ受注
- バイト代の使い方: 高級キーボード・高スペックサーバー・父の銀色のキーボードの修理費・Nei へのパンの差し入れ
- バイト収入 = Ren の生活費 + News Hacker 活動費。母からの送金は *受け取っていない*

### 読切の役割（再定義）

読切は「中学生時代に Ren がはじめて Kurosagi-Net 末端と接触した事件」の記録として、連載より 2 年前の *原点* の位置づけ。教室で寝ている Ren は中学生時代の姿。

### 食いしん坊設定の帰属

食いしん坊属性は **Nei に帰属** する。

- **Ren**: 食べ物への執着が薄い。Nei が差し入れるパンやおにぎりを事務的に口に入れるだけ（味わわず燃料として摂取）
- **Nei**: Ren の家の冷蔵庫を漁る・コンビニで 5 種類のパンを買って全部食べる・Ren のおにぎりの梅干しだけ抜いて食べる・パンのメーカーをパッケージなしで当てる特殊能力

読切時点の Ren のドーナツ粉付着ギャグは *中学生時代の残滓* として許容するが、連載では Nei が食事周りの喜劇をほぼ独占する。

## 3. 世界観と戦闘ルール

### 3.1 二層世界

- **物理世界**: 教室・蓮の家・街・病院・オフィス・海外ロケ
- **情報空間（ゴースト場）**: サーバー・パケット・Ghost（情報生命体）が物質化した空間
- **SIP デバイス**: Ghost を物理世界へ引き落とす装置（Ren 開発）
- **NULL AXE**: Ghost を情報論的に切断する武器（Ren 専用）

バトルは両層で同時進行。片方だけ勝っても事件は終わらない。

### 3.2 情報物理バトルのルール

| 原理 | 作中ルール |
| :-- | :-- |
| ランダウアー原理 | 情報消去 = 熱発生。犯罪者は必ず熱の痕跡を残す |
| シャノン情報エントロピー | 犯罪者のコードは不確実性が高い。歪みで見つける |
| 情報 = 物理資源 | サーバーの電力・冷却・回線が犯罪のボトルネック |
| Ghost の物質化 | SIP デバイスで一時物理化。この時だけ物理攻撃が有効 |

## 4. 3 美徳 × 努力・友情・勝利 のマッピング

### 4.1 美徳の定義（本作仕様）

| 美徳 | 人物 | プログラマ的意味 | 信念 |
| :-- | :-- | :-- | :-- |
| **怠惰 (Laziness)** | Ren | 長期で楽をするために短期で尋常じゃなく働く | 一件ずつ潰すのは、怠惰のやることじゃない。*根っこを切る。一回で* |
| **傲慢 (Hubris)** | Kaname | 他人に文句を言わせないコードを書く | 自分が *正しく手続きを踏めば* 、法がそれを受け入れるしかない |
| **短気 (Impatience)** | Chise | コンピュータが遅いと怒れる | 犯罪が動く *速度* を、*怒り* で上回る |

### 4.2 努力・友情・勝利との接続

- **努力**: 3 美徳が *怠けるための努力・傲慢のための完璧・短気のための速度* に向かう
- **友情**: 3 美徳は単体では *偏り* だが、3 つが合わさると *機能* になる。バディ制の根拠
- **勝利**: 3 美徳が揃った瞬間に *犯罪組織の罪悪（4 悪徳）* が対消滅する

### 5.2 4 悪徳の犯罪タイプ

| 悪徳 | 犯罪種 | 歪んだ美徳対応 |
| :-- | :-- | :-- |

### 5.3 敵の "顔" は必ず見せる

各アーク末端オペレータ〜幹部〜支部長〜中枢の順に、*誰か 1 人の顔* を 1 コマは必ず描く。

- Ren が攻撃した先には、必ず *人* がいる
- 組織犯罪を *抽象的な悪* で処理しない
- ただし共感させすぎず、*選択* の責任は本人に帰す

## 7. 神経多様性と吃音の扱い

### 7.1 原則

- **「障害」ではなく「特性・強み」**
- **ステレオタイプを避ける**（「集中力がない＝ダメ」「かわいい変人」等の消費表現を禁止）
- **治る／治らないの二項対立を避ける**
- **コメディは特性そのものを笑いの対象にしない**

### 7.2 各キャラの描写ルール

| キャラ | 特性 | 描写の規則 |
| :-- | :-- | :-- |
| Ren | ADHD | 過集中を *夜のハンター能力* に、注意散漫を *昼のコメディ* に分岐 |
| Nei | ASD (アスペルガー型) | 丁寧語・数値化癖を天然ボケに、感覚過敏のシャットダウンをシリアスに分岐 |
| Kaname | 高機能型サイコパシー | 感情の平坦さを *ギャップのボケ* に、情動的共感の欠落をシリアスな葛藤に分岐 |
| Chise | ASD (感覚過敏型) | 直接性をツッコミに、感覚過負荷をシリアスに分岐 |
| Ayumu | 発達性吃音 | チャットの流暢さを *省エネボケ* に、対面の詰まりは *ネタにしない* |

### 7.3 監修体制

- 児童青年精神医学会所属医師
- 日本吃音・流暢性障害学会所属の言語聴覚士
- 当事者団体（ADHD / ASD / 吃音）
- 司法精神医学の専門家（サイコパシー描写）

## 8. サイバーセキュリティ描写の品質基準

### 8.1 原則

- **手口は正確に、実害は過剰演出しない**
- **犯罪手口の *手引き* にならない丁寧さ**
- **被害者を責めない**（「あなたが悪かった」を台詞・構図で絶対に描かない）
- **いますぐできる対策を NeiPuni で必ず提供**

### 8.2 NeiPuni コーナーの品質基準

| 必須項目 | 毎回 |
| :-- | :-- |
| その回の攻撃手口の図解 | 必須 |
| いますぐできる対策 3 つ | 必須 |
| 公的窓口の番号 | 必須（#9110 / 188 / IPA） |
| 情報物理の豆知識 | 必須（科学との接続） |
| 「あなたは悪くない」メッセージ | 必須 |

### 8.3 監修

- JPCERT/CC
- IPA（情報処理推進機構）
- 警察庁サイバー犯罪対策プロジェクト
- 消費者庁・消費生活センター
- 各 SNS 運営の現行公式手順
- 掲載時点の最新情報へのアップデート体制

## 13. 成功条件

方向 III が成功したと言えるのは、以下の 5 つを同時に達成した時:

1. **読者が Ren を好きになる**: 「寝てる蓮可愛い」と「怠惰に信念がある」の両方が成立
2. **読者が情報科学を好きになる**: 「Cookie ってそう使うんだ!」「ランダウアーってこの人だったのか!」の驚き
3. **読者が被害者にならない**: 読了後、実際の IT リテラシーが上がる
4. **読者が友達に話したくなる**: 各話 1 つ、友達にドヤれる豆知識が生まれる
5. **読者が長く読み続ける**: 55〜65 巻、離脱せず読める
